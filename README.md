# 🍴 Zomato Data Analysis

This repository contains a comprehensive **Exploratory Data Analysis (EDA)** on Zomato’s restaurant dataset, featuring **2,00,000+ restaurant records**.  
The goal is to uncover **customer preferences, dining patterns, and service features** that influence restaurant ratings and success.  

---

## 📊 Key Insights
- 🌆 **City trends** – Pune, Bangalore & Amritsar record some of the highest average ratings, while metros dominate in restaurant count.  
- 🍻 **Premium formats** (Pubs, Lounges, Microbreweries) consistently score the best ratings.  
- 🍕 **Cuisines** – North Indian & Fast Food dominate in availability, while Continental & Italian cuisines receive higher satisfaction levels.  
- 📲 **Convenience matters** – Restaurants with **online ordering** & **table booking** see better ratings.  
- ⭐ **Customer sentiment** is largely positive, with over **60% reviews rated as Good/Very Good**.
